# Layout page

`newtek-lc11-layout.companionconfig` is a one-page Companion export: every LC-11 control in its grid
position, labeled as printed on the panel, with black backgrounds so the panel's lights stay off. The knob
positions already have Rotary Actions turned on.

Import it on Companion's **Import/Export** page onto an empty page, then use it as a map (or a starting
point) when assigning actions to the panel.
